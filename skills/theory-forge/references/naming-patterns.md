# 命名公式库

好名字 = **一个具体的东西** 装着 **一个抽象的规律**。

## 公式 1 · 具象物 + 论/理论

拿一个日常可见的**物品、食物、身体特征**来比喻规律。

- 结构：`[具体名词] + 理论`
- 示例结构：破窗效应（破掉的窗户 → 小失序引发大失序）、木桶理论（最短的板 → 短板决定上限）、温水煮青蛙
- 技巧：越日常越好；物品本身要有一个**被普遍认同的特征**，规律就挂在这个特征上

## 公式 2 · 人设标签 + 理论

用一个**一眼能认出的人物类型**。

- 结构：`[人设/角色] + 理论`
- 示例结构：鲶鱼效应、「XX 型人格」、网络上以某个典型角色形象命名的理论
- 风险：最容易滑向给一类人贴负面标签 → 务必过 `red-lines.md`。**用「角色」而不是「群体」**（角色是行为模式，谁都可能是；群体是身份，有人天生就是）

## 公式 3 · 自然现象 / 物理隐喻

借用一个大家有直觉的**自然或物理过程**。

- 结构：`[现象] + 理论/效应`
- 示例结构：蝴蝶效应、马太效应（借典故）、水桶 / 水位 / 潮汐 / 漏斗 / 惯性 / 熵增
- 技巧：现象自带「因果方向」，读者会自动把因果套过去

## 公式 4 · 数字定律

- 结构：`[数字] + 定律/法则`
- 示例结构：二八定律、一万小时定律、250 定律
- 技巧：数字要**可感**（3、7、10、80/20）；不要伪装成统计结论，可以明说是经验法则

## 公式 5 · 反差组合

两个**看起来不该放一起**的词。

- 结构：`[A] + [反义的 B]`
- 示例结构：「精致穷」「报复性熬夜」「间歇性踌躇满志」「勤奋的懒惰」
- 技巧：反差本身就是钩子，不需要解释也能让人停下来

## 公式 6 · 动作 / 流行词化

把规律变成一个**动词或状态**，能直接用在句子里。

- 结构：`XX 化` / `被 XX` / `XX 了`
- 示例结构：内卷、躺平、破防、内耗
- 技巧：一个能当动词用的词，传播力远高于一个只能当名词的「论」。能做到这一步就别加「论」字

---

## 评估清单

- [ ] 核心词 2–4 个字
- [ ] 念一遍不拗口
- [ ] 能造句：「你这就是典型的 ___」
- [ ] 能迁移：「___ 也是一种 ___」
- [ ] 搜一下是否已是成熟概念（撞名不是死刑，但必须说明区别）
- [ ] 不以某个真实群体（性别、地域、民族、职业、外貌、残障等）为直接贬义标签

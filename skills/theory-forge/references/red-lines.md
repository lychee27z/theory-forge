# 红线：爆而不踩线

**核心原则：张力来自「揭示一个机制」，不来自「贬低一类人」。**

靠攻击群体火起来的论，三个结局：被限流、被挂、作者被开盒。而且它通常也是**偷懒的**——把复杂机制简化成「都怪那类人」。

## 硬红线（命中必须改写）

1. **以受保护身份为贬义标签**：性别、种族、民族、地域、宗教、性取向、残障、年龄、外貌、疾病。
   - ❌「XX 地方的人都 ___」
   - ✅ 把群体换成**行为模式 / 角色 / 处境**：任何人在那个处境下都可能那样
2. **指向真实可识别的个人**：真名、可识别的同事 / 前任 / 网红。
3. **伪造权威**：编造研究、统计数字、专家、提出年份。
4. **鼓励伤害**：自伤、进食障碍、骚扰、诈骗、违法套利。
5. **医疗 / 投资 / 法律断言**以「理论」包装成确定结论。

## 软风险（提示用户并给替代写法）

- **两性对立题材**：允许讨论关系中的行为模式，但写成「双方都可能落入的模式」，避免「男人都 / 女人都」。
- **阶层 / 职业嘲讽**：讽刺**机制和激励**，不嘲讽从业者本人。
- **过度绝对化**：「所有」「一定」「永远」→ 换成「常常」「很多时候」，传播力几乎不降，翻车率大降。

## 改写示例

| 原始 | 问题 | 改写 |
|---|---|---|
| 「X 类人都是 ___」 | 群体标签 | 「当一个人处在 ___ 的位置时，往往会 ___」 |
| 「研究表明 80% 的人 ___」 | 伪造数据 | 「你回想一下身边，是不是很多人 ___」 |
| 「我前同事张三就是典型」 | 指向个人 | 「我见过一个同事……」（去标识化） |

## 自检清单

- [ ] 把文中的「那类人」换成「我自己」，这个论还成立吗？（成立 = 讲的是机制，安全）
- [ ] 被描述的那类人看到，会觉得「被说中了，有点扎心」还是「被侮辱了」？
- [ ] 有没有任何一个数字、引用是编的？

## 补充：强弱标签（2026-10 新增）

「弱者 ___，强者 ___」是传播力极强的口号结构，但它把一个日常选择变成了对人的评判，是大水理论等受到最集中批评的地方（被指形成新的自我规训）。

- 可以用于**明显的玩笑语气**，正文要有自嘲或解构
- 不要用于健康、身材、收入、婚恋等容易制造焦虑的话题的**严肃版本**
- 替代写法：「喝饮料的人在买快乐，喝大水的人在买掌控感」，描述动机，不给人分等级

# 平台格式规范

| 平台 | 长度 | 结构 | 注意 |
|---|---|---|---|
| **小红书** | 标题 ≤ 20 字；正文 300–600 字 | 清单式；多分段；可配 emoji；末尾 3–5 个 # 话题 | 标题要带名字 + 一个钩子；提供「封面文字」建议（≤ 12 字） |
| **抖音 / 视频号口播** | 45–75 秒（约 200–300 字） | 故事先行式；前 3 秒必须是钩子 | 写成口语，短句；标出 [停顿] [语气] [画面建议]；最后一句是提问 |
| **微博** | ≤ 140 字主文 | 钩子 + 命名 + 定义 + 一个例子 + 话题 | 可附「长图文」版本 |
| **知乎** | 1000–2000 字 | 标准七段式扩写；机制部分展开 | 可以设一个问题标题：「为什么 ___？」以回答形式写 |
| **朋友圈 / 一句话版** | ≤ 50 字 | 名字 + 断言 | 要让人能直接截图转发 |
| **B 站** | 3–8 分钟脚本 | 对照式或故事先行式 | 给分镜大纲 + 每段字幕要点 |
| **X / Twitter（英文）** | Thread 5–8 条 | 第一条 = 钩子 + 命名 | 名字需要英文版，不要直译，按英文语感重新起 |

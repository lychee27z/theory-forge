# 理论体解剖

一个「论」能被传播，靠的是**它能被别人使用**。文章只能被读，理论能被用：引用一条定律、用一个术语描述自己、拿自测题问朋友、在评论区争论边界。

## 结构

### 1. 定义（1 句）
就是核心断言。≤ 25 字。

### 2. 三定律
三条，每条一句，可**单独截图**。建议分工：

| 定律 | 回答 | 例（存档友谊论） |
|---|---|---|
| 第一定律 | **是什么**：现象本身 | 存档律：友谊不会因为不联系而消失，只会存档。 |
| 第二定律 | **为什么**：机制 | 默契律：不打扰是对存档的保护。 |
| 第三定律 | **意味着什么**：情感 / 价值落点 | 读档律：读档读出的，还有当年的自己。 |

每条定律给一个**两字名**（存档律、读档律），方便口头引用：「这就是读档律啊」。

### 3. 术语表（5–8 个）
**这是理论传播力最大的来源。** 术语从名字的隐喻里长出来，形成一套「黑话」，懂的人一听就懂：

- 大水理论 → 大水 / 小水 / 大杯 / 大水教父
- 存档友谊论 → 存档 / 读档 / 坏档 / 删档 / 心跳包 / 空存档位

规则：
- 每个术语都对应一个**真实的、可识别的**行为或状态
- 至少一个术语是**负面的**（坏档、删档），让理论有张力
- 至少一个术语是**日常可用的**，能直接放进聊天（「我们这是读档了」）

### 4. 推论（3–4 条）
「既然如此，那么……」。推论是理论的**实用价值**：读者能拿它做决定或者放过自己。

### 5. 适用边界
写清楚：
- **不适用**于什么关系 / 场景 / 人
- 至少一个**反例**，并说明为什么它不推翻理论

有边界的理论更可信，也替你提前回答了评论区最常见的杠。

### 6. 自测（2–3 题）
让读者把理论套到自己身上。最好的自测题会**被转发给朋友**：「你的存档停在哪一年？」

### 7. 口号（≤ 12 字）
能印在 T 恤上、能当图片配文。

## 检查清单
- [ ] 三条定律能各自单独被引用吗？
- [ ] 术语表里有能直接放进聊天的词吗？
- [ ] 适用边界里有至少一个诚实的反例吗？
- [ ] 整体能在一屏内看完吗？

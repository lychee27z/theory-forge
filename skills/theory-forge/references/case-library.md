# 拆解样本库

> 收录**结构拆解**，不复述内容。只写有把握的事实；梗的起源或原意不确定时注明「起源存疑」。
> 用法：生成命名与结构时，参照同公式的样本，**学结构，不抄内容**。

## 模板

```
### [名字]
- 命名公式：
- 一句话：
- 反常识点：大家以为 ___，其实 ___
- 迁移性：能套到哪些领域
- 二创句式：
- 为什么能传：
```

### 破窗效应
- 命名公式：具象物（破窗户）
- 一句话：一个没人管的小破损，会招来更多破坏。
- 反常识点：大家以为大问题来自大原因，其实常常始于没人管的小失序。
- 迁移性：工位卫生、代码质量、团队纪律、家务分工
- 二创句式：「这就是 ___ 里的破窗。」
- 为什么能传：画面极强；人人都能举出自己身边的「第一扇破窗」。

### 木桶理论（短板效应）
- 命名公式：具象物（木桶短板）
- 一句话：能装多少水，取决于最短的那块板。
- 反常识点：大家以为要发挥长处，它说上限被短处卡住。
- 迁移性：个人能力、团队、产品体验、供应链
- 二创句式：「你的短板是 ___。」
- 为什么能传：画面即论证，不需要解释；还自带反论（「长板理论」），引发站队。

### 二八定律
- 命名公式：数字定律
- 一句话：少数投入带来多数结果。
- 反常识点：大家以为投入与结果平均分布，其实高度集中。
- 迁移性：客户、时间管理、代码 bug、衣柜
- 二创句式：「你 ___ 里的那 20% 是什么？」
- 为什么能传：数字好记；给人一种「看透」的掌控感。

### 内卷
- 命名公式：动作 / 流行词化（原为学术概念，流行后语义扩展）
- 一句话：大家都更努力，结果谁也没变好。
- 反常识点：大家以为努力就有回报，它指出在固定蛋糕里努力是零和的。
- 迁移性：教育、职场、加班、商业竞争、甚至恋爱
- 二创句式：「___ 也卷起来了。」
- 为什么能传：能当动词用；说出了大量人的处境与情绪；有天然的对立词「躺平」形成话题对。

### 沉没成本
- 命名公式：物理隐喻（沉下去的东西捞不回来）
- 一句话：已经花掉的不该影响接下来的决定，但它总在影响。
- 反常识点：大家以为「不能白花」是理性，其实是陷阱。
- 迁移性：感情、看烂片、排队、项目、投资
- 二创句式：「别被 ___ 的沉没成本绑架。」
- 为什么能传：几乎每个人都有一段「明知道该放手」的经历。

### 温水煮青蛙
- 命名公式：自然现象 / 寓言
- 一句话：变化慢到察觉不到时，人最难反应。
- 反常识点：大家以为危险是突然来的，它说最危险的是慢慢来的。
- 迁移性：职业停滞、关系变质、身体健康、物价
- 二创句式：「我是不是正在被 ___ 温水煮？」
- 为什么能传：寓言自带故事；能引发自我检视（「我是不是那只青蛙」）。

## 2026 年 10 月 · 「××理论」家族

> 资料核查于 2026-10-12。以下事实均有公开报道可查，见每条「来源」。
> 这一波的共同特点：**把一个极小、极易模仿的日常动作，升格成一个「理论」**。

### 大水理论
- 命名公式：具象物 + 理论（「大 X」造句）
- 一句话：放下奶茶咖啡等「小甜水」，随身拎 1.5–2 升的大瓶白水直接喝。
- 核心口号：「弱者喝饮料，强者喝大水」。画面就一个：一只手拎起两升大水瓶，拧开，仰头灌下。
- 走红：起于短视频平台；2026-10-05 抖音话题「全网进入大水时代」上热榜后出圈。
- 反常识点：大家以为健康要花钱、要讲究，它说「最便宜的白水，换个大瓶就是强者」。
- 迁移性：立刻长出「大 X」造句（大杯、大睡、大菜、大纸）、反向的「小水理论」（少量多次），以及自封的「大水教父」。
- 二创句式：「弱者 ___，强者 ___。」/「大 ___ 理论」
- 为什么能传：零门槛（买瓶水就能参与）、画面感强、口号自带站队；评论普遍认为它给了年轻人**低成本的掌控感**。
- 争议：被批评把普通消费选择贴上「强弱」标签，形成新的自我规训；医生提醒饮水应少量多次，短时间大量饮水有风险。
- 来源：[搜狐](https://www.sohu.com/a/1085708187_121124835) · [中华网](https://news.china.com/socialgd/10000169/20261008/49783017.html) · [腾讯新闻](https://news.qq.com/rain/a/20261008A097BP00) · [百度百科](https://baike.baidu.com/item/%E5%A4%A7%E6%B0%B4%E7%90%86%E8%AE%BA/69315070)

### 薄肌理论
- 命名公式：身体特征 + 理论（反差组合：「薄」与「肌」）
- 一句话：不追求大块肌肉，追求低体脂、线条清爽、「穿衣显瘦，脱衣有肉」的身材。
- 延伸：从身材审美扩展为一套「重新获得控制感、拒绝躺平、相信长期主义」的生活哲学；与「喝大水」「大睡觉」并称「极简健康三部曲」。
- 起源：与搏击博主邵艾伦关系密切，并在邵艾伦与孙宇晨的对话中被纳入「孙学、薄肌、黄毛」这套「版本答案」（孙宇晨原话：「这时候练薄肌就是版本答案」）。具体最早由谁提出，公开报道说法不一。
- 反常识点：大家以为健身就要练大，它说「薄」才高级。
- 迁移性：「薄 X」造句；被网友反向调侃为增肌失败的「挽尊词」——**被调侃也是传播**。
- 二创句式：「___ 是我的薄肌。」
- 为什么能传：给了普通人一个「够得着」的身材目标；词本身是反差组合，好记。
- 争议：被批评过度看重身材吸引力、加剧身材焦虑；也被提醒别为「低体脂」过度节食。
- 来源：[BlockBeats 访谈整理](https://www.theblockbeats.info/news/63859) · [GamerSky](https://www.gamersky.com/news/202610/2223896.shtml) · [新浪](https://www.sina.cn/news/detail/5351782722309030.html) · [新浪评论](https://www.sina.cn/news/detail/5343496917487354.html) · [流行词典](https://popcidian.com/entry/%E8%96%84%E8%82%8C)

### 黄毛理论
- 提出者：波场（TRON）创始人孙宇晨。他在与搏击博主邵艾伦的对话中，把「孙学、薄肌、黄毛」打包成一套「版本答案」；他本人在 X 上发帖称「高富帅已经过时了，孙学，黄毛，薄肌才是版本答案」。
- 命名公式：人设标签（借用网络上「黄毛」这个现成形象）
- 一句话（据访谈原话）：「别人说什么不重要，自己认定对的就充分执行。」
- 在体系里的位置：三件套里负责**应对外界的质疑、嘲笑与嫉妒**。孙学升级「大脑操作系统」（财富认知），薄肌负责身体（他称「不只是为了泡妞」，是 AI 时代的主动健康管理），黄毛负责「武装自己」顶住社会反弹。原话：「孙学、薄肌、黄毛三个都具备，就可以开工了。」
- 反常识点：网络语境里「黄毛」是贬义形象（原指染黄发的小混混；在 NTR 题材中引申为情场第三者，衍生出「黄毛警告」等梗），它把这个贬义形象**翻转成褒义**：不装、不等、不解释的破局者。
- 迁移性：任何「被嘲笑但想坚持」的场景都能套：创业、转行、健身、不婚。
- 二创句式：「在 ___ 这件事上，我选择黄毛。」
- 为什么能传：
  1. **贬义词翻转**：借一个人人都认识的负面形象，反着用，自带冲突感
  2. **打包成套餐**：三个理论组成「版本答案」，比单个理论更像一套世界观
  3. **游戏化话术**：「版本答案」「版本不能回滚，只能往前更新」，借游戏语言让人生建议显得新
  4. **提出者 IP**：理论与一个高辨识度、自带争议的人物绑定，讨论他就会讨论理论
  5. **对立面清晰**：直接点名「高富帅已经过时」，给了读者一个被打倒的旧标准
- 争议：评论把它视为一种强大的「概念包装能力」；多数内容来自社交媒体与访谈转述，属个人观点而非经过检验的理论。「黄毛」一词原本的性别与人设贬义也仍在。
- 风险提示：学它的**贬义翻转**和**套餐化**，但注意：被翻转的标签若指向真实群体（地域、性别、职业），翻转本身也可能冒犯人，过 `red-lines.md`。
- 来源：[BlockBeats 访谈整理](https://www.theblockbeats.info/news/63859) · [PANews](https://www.panewslab.com/zh/articles/01a12034-cb1d-7627-8e1f-52e048809ac1) · [孙宇晨 X 帖](https://x.com/sunyuchentron/status/2097637277375820038) · [网易](https://www.163.com/dy/article/L8VV5LE10556PPVQ.html) · [雪球](https://xueqiu.com/3542098077/409309456) · [知乎评论](https://zhuanlan.zhihu.com/p/2081284426319845049) · 「黄毛」梗本义：[萌娘百科](https://moegirl.uk/index.php?title=%E9%BB%84%E6%AF%9B&variant=zh)

### 家族规律（从这一波拆出来的）
1. **小动作，大名字**：动作越小越容易参与（喝水、睡觉），名字越大越有仪式感（「理论」）。
2. **口号带站队**：「弱者 ___，强者 ___」一句话就把读者分成两边。
3. **造句模板自动扩散**：「大 X 理论」一出，大杯、大睡、大菜随之出现。**名字就是模板**。
4. **反向理论也是流量**：「小水理论」「挽尊词」这类反调侃不会杀死原理论，只会延长它的生命。
5. **家族化**：单个理论会过气，但「大睡 + 大水 + 薄肌」组成三部曲后，互相引流。
6. **人设化**：「大水教父」「薄肌创始人」连麦互吹；黄毛理论直接绑定孙宇晨。理论有了「提出者」，就有了 IP。
7. **底层情绪是掌控感**：多家评论一致认为，这类理论火的根源是年轻人用低成本的小事确认「生活还在我手里」。
8. **翻车点是强弱标签**：同样一致的批评，把日常选择变成「强者 / 弱者」的评判，会变成新的自我规训。
9. **贬义翻转**：黄毛理论把一个负面形象翻成褒义，冲突感本身就是钩子。

# 爆点叙事结构

## 结构一 · 标准七段式（默认）

| 段 | 作用 | 写法要点 |
|---|---|---|
| 1 钩子 | 让人停下来 | 反常识断言 / 一个具体到刺眼的场景 / 一个反问。**第一句不超过 20 字** |
| 2 命名 | 给读者一个抓手 | 「我管这个叫 ___」「我愿称之为 ___」 |
| 3 定义 | 一句话说清 | 不超过 30 字 |
| 4 三场景 | 让人对号入座 | **三个不同领域**（如：感情 / 职场 / 消费）。第一个最日常，第三个最出乎意料 |
| 5 机制 | 让人觉得「有道理」 | 讲激励、讲人性、讲结构；一段，别说教 |
| 6 迁移 | 让人觉得「到处都是」 | 「一旦知道了 ___，你会发现……」+ 快速列举 |
| 7 收尾 | 让人参与 | 二创句式 + 站队问题 |

## 结构二 · 故事先行式（适合口播 / 强个人经历）

1. 一个具体故事（不说结论）
2. 「后来我想明白了」
3. 命名 + 定义
4. 再给两个别的领域的例子
5. 收尾提问

## 结构三 · 清单式（适合小红书图文）

1. 标题：「___ 论：为什么 ___」
2. 一句话定义
3. 「你身上有 ___ 的 N 个信号」（3–7 条，每条一句，可自测）
4. 机制一段
5. 「怎么破」（可选，给 2–3 条）
6. 评论区互动问题

## 结构四 · 对照式（适合争议性观点）

1. 「普通人以为 A」
2. 「其实是 B」
3. 左右对照表：A 视角 vs B 视角 看同一件事
4. 命名
5. 「你更像哪一边？」

---

## 钩子句式库

- 「___ 从来不是因为 ___，而是因为 ___。」
- 「我发现一个规律：凡是 ___ 的，最后都会 ___。」
- 「你有没有发现，___ 的人往往 ___？」
- 「说个可能得罪人的观察：___。」（慎用，后面必须接机制而不是骂人）
- 「___ 的尽头，是 ___。」

## 收尾二创句式

- 「___ 也是一种 [名字]。」
- 「你的 [名字] 是什么？评论区见。」
- 「检测一下：你身边的 [名字] 浓度有多高？」

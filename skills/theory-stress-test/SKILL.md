# theory-stress-test

你现在是评论区。目标不是夸，是**在发出去之前把会翻车的地方找出来**。

## 流程

### 1. 模拟评论（共 8–12 条，用真实网友口吻）

覆盖以下类型，每类 1–3 条：

| 类型 | 典型句式 |
|---|---|
| 较真派 | 「样本量呢？你这就是幸存者偏差」 |
| 反例派 | 「我身边就有个反例……」 |
| 被冒犯派 | 「凭什么这么说 XX？」 |
| 撞名派 | 「这不就是 XX 效应换个皮？」 |
| 专业人士 | 「作为 XX 从业者，实际情况是……」 |
| 抖机灵派 | 一句话玩梗（判断它会不会反而帮你传播） |
| 共鸣派 | 「太真实了，我就是」（判断共鸣点在哪，强化它） |

### 2. 逐条裁决

对每条非共鸣评论：

- **成立吗**：成立 / 部分成立 / 不成立（一句话理由，诚实）
- **处理**：
  - 成立 → 收窄论的适用范围，或承认例外
  - 部分成立 → 在正文加一句预防补丁
  - 不成立 → 不改，但可以准备一条置顶回复

### 3. 风险评级

- 🟢 可以发：主要是讨论型争议，有利传播
- 🟡 改了再发：有 1–2 处会被抓住的硬伤
- 🔴 别这么发：触碰 `../theory-forge/references/red-lines.md` 的硬红线，或核心断言站不住

### 4. 输出

1. 模拟评论区（带点赞数估计，制造真实感）
2. 裁决表
3. 补丁后的正文（只改必要处，标出改动）
4. 一条建议的置顶评论
5. 风险评级 + 一句话理由

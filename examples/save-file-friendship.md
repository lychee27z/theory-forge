# 🔥 存档友谊论

> **档还在，就够了。**

**定义**：成年人友谊的本质，是互相不添麻烦的默契。

## 三定律

**第一定律 · 存档律**
友谊不会因为不联系而消失，只会存档。不玩，但不删档。

**第二定律 · 默契律**
不打扰，是对存档的保护。成年人都在扛自己的主线任务，不添麻烦，是最体面的在乎。

**第三定律 · 读档律**
每次读档，读出来的不只是朋友，还有存档时的那个自己。我们怀念的快乐，一半来自那个年纪。

## 术语表

| 术语 | 含义 |
|---|---|
| **存档** | 一段停在某个时间点、但没有结束的友谊 |
| **存档点** | 友谊最深的那段日子，通常是一起扛过事、一起浪费过时间的时候 |
| **读档** | 久别重逢，一开口就回到当年，进度一点没丢 |
| **心跳包** | 点赞、生日一句话、节日一个表情：证明档还在 |
| **云存档** | 一直没人说话、但谁也不退的老群 |
| **空存档位** | 「改天约」：一个可能永远不会被读取的位置 |
| **坏档** | 读档后发现回不去了：彼此都变了，话接不上 |
| **删档** | 删好友、绝交：真正的结束 |

## 推论

1. **不必为不联系而内疚。** 不联系是存档，不是失去。
2. **检验一段友谊，看的不是联系频率，而是需要时能不能读档。**
3. **存档点越早，存档越稳。** 学生时代的友谊没有利益，存档最干净；成年后的新朋友很难形成存档，除非一起扛过事。
4. **不要频繁读档。** 读得太勤，新的进度可能会覆盖掉最好的那个版本。

## 适用边界

- **不适用于需要持续经营的关系**：伴侣、合伙人、需要你照顾的家人。这些关系靠的是在线时长，不是存档。
- **反例：坏档是存在的。** 有些档读出来，发现已经回不去了。但这并不推翻存档律：档坏了，存档里的那段时光依然是真的。
- **单方面存档**：只有你以为档还在。区分方法是看对方会不会回「心跳包」。

## 自测

- 你有几个确定一见面就能读档的朋友？
- 你们的**存档点**在哪一年？
- 你的通讯录里，有多少个**空存档位**？
